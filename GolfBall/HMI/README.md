# GolfBall — HMI

**Terminal:** RedLion CR1000-07000

**Software:** Crimson 3.2

## Overview
The main operator interface of this machine. Initialization values are entered on the HMI, as well as config of all customizable capabilities.
Displays all relevant machine state information, including descriptive fault messages.

## Screens
| Screen | Purpose |
|--------|---------|
| Home  | Status overview |
| Alarms | Alarm/Fault viewer |
| NumberofPositions | Step 1 of Init |
| AreTubesClear | Step 2 of Init |
| Tube1Init | Opt. Init step |
| Tube2Init | Opt. Init step |
| Tube3Init | Opt. Init step |
| Config | Main config overview |
| IOLanding | Display of data tags |
| PageSelection | Page Selection menu |
| SelectSortMenu | Sorting config Page Selection submenu  |
| T1_Sort | Sorting config of tube 1 |
| T2_Sort | Sorting config of tube 2 |
| T3_Sort | Sorting config of tube 3 |
| Manual | Manual machine control |

## Notes
- Comms via TCP/IP over Ethernet
